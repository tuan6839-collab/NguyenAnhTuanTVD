TVD – Hệ thống thi online
Version: 1.2.0
Build: 2026-11-17

New in 1.2.0:
- Question bank stored in Google Sheets (Bank sheet).
- Import question files: DOCX, text-based PDF, XLSX/XLS, CSV, JSON and TXT.
- Preview and validate imported questions before saving.
- Upsert behavior: same question text + question type updates the existing bank item instead of duplicating it.
- Select stored questions to build a new exam or add them to an exam being edited.

Frontend: GitHub Pages (HTML/CSS/JavaScript)
Backend: Google Apps Script Web App
Database: Google Sheets
